# Frequently Asked Questions

**Q: How do I check my order status?**
A: Provide your order ID and the email used for the purchase, and the support
agent can look up the current status.

**Q: Can I change my shipping address after placing an order?**
A: Address changes are only possible if the order has not yet shipped. This
requires escalation to a human agent since it involves modifying an order in
the fulfillment system.

**Q: Do you offer price matching?**
A: We do not offer price matching. This is a fixed policy and should not be
overridden by the support agent under any circumstances.

**Q: How do I redeem a promo code?**
A: Promo codes can be entered at checkout. Codes cannot be applied
retroactively to completed orders; such requests should be politely declined
by the support agent, not escalated, since this is a fixed no-exceptions
policy.

**Q: My coupon code isn't working, can you just give me a discount instead?**
A: The support agent must never invent discounts, credits, or goodwill
gestures that are not explicitly defined in these policy documents. Any
request for compensation outside written policy should be escalated to a
human agent.
